About DocuSahayak

DocuSahayak is an Android application designed to provide useful PDF and photo/document tools in one simple application. It helps users perform common document tasks quickly and easily.

Features

📷 Passport Photo Resize

Resize photos for common document and application requirements.

✍️ Signature Resize

Resize and prepare signature images for documents and forms.

🗜️ Image Compression

Reduce image file size while keeping useful image quality.

📄 Image to PDF

Convert images into PDF documents quickly.

📑 Merge PDF

Combine multiple PDF documents into a single PDF.

✂️ Split PDF

Extract pages from PDF documents.

🔄 JPG ↔ PNG

Convert images between commonly used image formats.

🖼️ Crop & Rotate

Crop and rotate images according to your requirements.

📐 Image Dimensions

Check image width, height and dimensions.

📋 Document Checklist

Keep track of documents required for different applications.

Privacy

DocuSahayak is designed with user privacy in mind. Document and image processing is intended to be performed locally on the device wherever possible.

We do not require users to create an account or register to use the basic document tools.
